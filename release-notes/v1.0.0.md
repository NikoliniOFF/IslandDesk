## 🏝️ IslandDesk для Windows 1.0.0

**Скачать:** `IslandDesk-1.0.0-win64.zip` ниже (или постоянная ссылка `IslandDesk-win64.zip`). Распакуйте и запустите `IslandDesk.exe` — вверху экрана появится остров, а значок — у часов.

### Что нового
- Первый выпуск: «Динамический остров» как на iPhone — чёрная пилюля вверху экрана плавно перетекает из формы в форму
- Музыка из Spotify, Яндекс Музыки, браузера и других плееров: обложка, название, кнопки и эквалайзер
- Громкость, яркость, раскладка RU/EN, Caps Lock и Num Lock, наушники Bluetooth с зарядом, батарея ноутбука
- Таймер в один щелчок: 1, 5, 10, 25 минут или свой; загрузки — «Идёт загрузка», потом «Скачано» с кнопками «Открыть» и «Показать в папке»
- Индикатор микрофона с выключением в один щелчок; уведомления от программ Nikolini; файл, брошенный на остров, открывается в PeekDesk
- Лёгкий: exe около 620 КБ, в простое не тратит процессор; у каждой функции свой переключатель, в играх и фильмах прячется сам

### Также в 1.0.0
- Колесо мыши над островом меняет громкость, над своим таймером — его длительность. Правый щелчок — быстрое меню.
- Можно прятать пилюлю, когда ничего не происходит, и выбрать монитор.
- Системное окошко громкости можно спрятать (только Windows 10; при выходе всё возвращается).
- Обновляется сама (режимы «Автоматически», «Спрашивать», «Не проверять»), запускается вместе с Windows (выключается).
- Бесплатно, без Pro-версии, без рекламы и без слежки: в интернет IslandDesk ходит только к GitHub за обновлениями.

### Ограничения первой версии
- Яркость — только для встроенных экранов ноутбуков (внешние мониторы по DDC/CI пока не поддерживаются).
- Раскладка, переключённая мышью через языковую панель, появится на острове после смены окна.
- Скрытие системного окошка громкости работает только в Windows 10.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 (1809 или новее) или 11, 64-бит.
