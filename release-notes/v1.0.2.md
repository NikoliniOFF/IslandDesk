## 🏝️ IslandDesk для Windows 1.0.2

**Скачать:** `IslandDesk-1.0.2-win64.zip` ниже (или постоянная ссылка `IslandDesk-win64.zip`). Распакуйте и запустите `IslandDesk.exe`. Если IslandDesk уже стоит, он обновится сам.

### Что нового
- Проверка обновлений больше не упирается в ошибку GitHub 403: IslandDesk теперь не использует лимитированный интерфейс GitHub, который был общим для всех программ на компьютере
- Если проверить обновления не получилось (нет интернета или GitHub занят), в фоне ничего не показывается — IslandDesk тихо попробует позже. При нажатии «Проверить обновления» вы увидите мягкое «Не удалось проверить, попробуйте позже»
- Новые значки SnapDesk, DockDesk и SpotDesk в «Другие программы от Nikolini»; у SnapDesk новое описание
- Обновление всегда проверяет контрольную сумму SHA-256 архива; без неё не устанавливается

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 (1809 или новее) или 11, 64-бит.
