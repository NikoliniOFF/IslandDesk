## 🏝️ IslandDesk для Windows 1.0.1

**Скачать:** `IslandDesk-1.0.1-win64.zip` ниже (или постоянная ссылка `IslandDesk-win64.zip`). Распакуйте и запустите `IslandDesk.exe`. Если IslandDesk 1.0.0 уже стоит, он обновится сам.

### Что нового
- Новый значок в общем стиле программ Nikolini: монитор, а у верхнего края экрана — светящийся остров
- «Другие программы от Nikolini» во вкладке «О программе»: все вышедшие программы со значками, HubDesk — первым
- Список программ обновляется при открытии настроек — новые программы Nikolini появятся без новой версии IslandDesk
- Без интернета показывается сохранённый или встроенный список; если значка нет — буква на цветном квадрате

### Исправлено
- Ключи `--enable` и `--disable` теперь сохраняются сразу, даже если программу потом закроют аварийно

### Также
- Список программ загружается с GitHub только при открытии окна настроек, не в фоне. Больше IslandDesk в интернет не ходит — кроме проверки обновлений (её можно выключить).
- Из-за встроенных значков exe подрос до ~800 КБ.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 (1809 или новее) или 11, 64-бит.
